# Ismael-Horror-Game-DGD3



#### What went well?

What went well for this project is that I already had scripts for the game to be in first person. I ended up reusing an old first person player movement, camera and shooting mechanic from one of my project of game Dev 2, So I didn't have to worry a lot about those scripts. I did have to break or add to those scripts, such as for the shooting i made it so you had a certain amount of ammo to kill enemies to help add on the scarcity. 

##### 

###### What didn’t go well?

I got stuck on the enemy trigger, I wanted it so in each room there's a trigger, where if the player steps on it, the enemies will spawn. I also had some problems with the player restart UI that took me a long time to figure out. 





###### What challenges did you face?

The challenge that I did face was being able to have a player interact system which took some time to figure out but I did it. Another challenge that I did face was, How do you open the door from once side but not the other. this was for the final room where the key was. Some other challenge I also faced was what didn't go well.





###### What can you do differently next time?

What I would do differently would to make this game in 3d person not first person. Fix the tile trigger so when the player walks into a certain area of the game, the enemies would spawn in. I would also want to add a "Boss" that drops the key to open the locked door. I think that would be really cool, maybe also add different enemies and maybe different weapons to make things even more fun.
